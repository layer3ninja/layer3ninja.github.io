# Why I'm building this site

Welcome! This is where I'll publish what I learn as a network engineer — from CCNP
ENCOR study notes to cloud networking and AI-for-networking experiments.

<!-- more -->

## What to expect

- **Study notes** organized by track (CCNA, CCNP, Security, Cloud, AI) in the top menu
- **Lab write-ups** — topology, configs, verification output and what broke
- **Troubleshooting guides** built around real `show` output

Writing things down forces me to understand them properly. If a note helps you too, great.
